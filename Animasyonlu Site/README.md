# Web tasarımı Sitesi

**Web Tasarımı** için tasarlanmış modern ve kullanıcı dostu bir tanıtım web sitesidir. HTML, CSS ve JavaScript kullanılarak geliştirilmiştir. Bu site, web tasarımı hizmetlerini tanıtmak, fiyat bilgilerini sunmak ve kullanıcılarla iletişime geçmek amacıyla yapılmıştır.

## Proje Özellikleri

- **Google Fonts** kullanarak modern bir yazı tipi (Poppins) ile tasarımı özelleştirme
- **Animasyonlu menü**: Modern bir menü geçişi ve açılma/kapama animasyonları
- **Mobil uyumlu**: Responsive tasarım, her cihazda düzgün görünüm
- **Hizmetler listesi** ve **fiyatlar**: Sunulan hizmetler ve fiyat bilgilerini kullanıcı dostu bir formatta sunma
- **İletişim bilgileri**: Firma iletişim bilgileri kolayca erişilebilir
- **Basit JavaScript animasyonları**: Sayfa geçişleri ve menü animasyonları

## Kullanılan Teknolojiler

- HTML5
- CSS3 (Responsive Tasarım)
- JavaScript (Animasyonlar)
- Google Fonts (Poppins)
